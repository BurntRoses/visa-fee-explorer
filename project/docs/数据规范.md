# 地区命名与人口／次数摘要

本项目遵循一个中国原则。中国香港、中国澳门、中国台湾为中国的组成部分，仅按原始出入境、护照与收费统计口径分列，不代表独立国家。CHN对应中国大陆；界面、覆盖表、摘要与生成数据统一使用上述名称。来源原始名称保留在原件和追溯字段，不改写原始资料。

国家／地区摘要按当年完整已建模边集生成，先合并申根、排除合并后同端点边，每笔费用计一次。摘要的全球范围可能大于当前图形选集。没有费用边显示“未识别”，明确免费边才显示0。

每次费用只在金额和同一行数量存在匹配口径时计算。申请、签发、结案、估算付费事件分别展示；不把入境游客或国籍分配代理当作申请次数，不把次数写成独立人数。摘要同时保留该分母所覆盖金额比例、公式和来源；没有合适数量时不生成申请人均值。

人口来自世界银行SP.POP.TOTL同年总人口，中国台湾使用同年年末户籍人口并注明；申根为工作台统一29成员集合的同年人口合计（历史年份亦使用该展示集合）。金额／人口表示规模折算，不是实际居民个人账单。缺年不回填，不把总人口当申请人。详情展示人口年份、口径与原件来源。

# 数据规范 r11

日期：2026-11-17；数据版本：`2026.11.17-r11`；工作台：`4.5.2`。JSON是主存储，CSV中对象和数组以JSON字符串保存。

## 1. 主金额契约

`F(A→B)`表示A国申请人支付给B国政府的签证费。国家流入是入边之和，流出是出边之和，差额＝流入－流出。全球规模每条边只加一次；全球流入和流出是同一笔钱。国家差额不表示政府利润，也不表示实际银行跨境结算。

`data/processed/flows.json`是当前金额主表。`routes.json`保留旧价目路线和原期，不能代替国家总额；`financial_ledger.json`是原期实际科目，不能再加到已校准边上。`build_money_model.py`生成替换范围，`build_flow_ledger.py`排除WORLD和美国地区小计，再由同一边集合导出余额和矩阵。

## 3. 实体与归属

优先使用ISO alpha-3。`UNK`、`UNK_*`及无法可靠映射的`RAW_*`是未分配来源；不按游客份额虚分国籍。未知来源金额已包含在目的地收到中，不能再加一次，也没有进入各具体国支出。

`SCH`仅为展示聚合，模型边的收款方是成员政府；全球不能再加一个SCH总额。地区视图覆盖29个成员辖区，原统计有28个独立签发政府；列支敦士登没有独立签发合计。地区内部流动排除，成员下钻保留真实归属。

目标是付款申请人国籍；原表国籍、递交地、居民地、发布方来源国、机构所在地分别保存。申根使用显式递交地→国籍参数，免签国家递交归未知国籍；加拿大访客／学习用原表来源份额代理，工作许可收入保留UNK；新加坡居民地近似国籍。韩国、越南已有金额模型，但付款来源仍保留UNK。转换并不把原统计变成观测国籍。

申根有效费率同时受申请国籍、收款成员政府和收费生效日期影响。优惠协定、适用成员与暂停安排由归档规则约束；不得给所有递交地或所有成员统一套一个优惠价。国籍分配会改变有效费率，共同情景需同时计算金额与范围。

逻辑键包含期间、对象、类别、指标和来源定位。全类与子类、地区与成员、小计与细项不能共同累加。日本互斥目的组由原始交叉边际分配；美国全部工作量类含免费0；英国按叶类别分区；澳洲600与实际VAC余项互斥。

## 4. 期间、数量和金额

当前费用时间轴覆盖2011–2025，金额边统一以`period_type=calendar_year_model`按自然年组织，原期实际另存观察。年份、目的地和类别的证据覆盖分别记录。2024／2025核心模型与历史、空间扩展模型按替换范围合并。美国按财年插值／最近年度运行率，澳洲2025改为两个完整财年收入各半，新西兰按完整财政期桥接；尼泊尔2023／2024按精确财年日数桥接、2025为最新FY水平代理。原财年日期和计算假设保留在参数／模型中。

`time_space`包补入2011–2014申根短期原表和美国CY2019／2020／2023收入桥接。申根使用原表当年25个独立收款政府，不把当代成员回填；2011／2012读取L列C申请，2013／2014读取I列C／统一短期申请，过滤汇总、非申根、ATV与边检记录。2011–2014的CNY／EUR／GBP年均汇率取Fed G.5A对应年度。摩尔多瓦2011–2013本国国籍份额为95%工作参数，2014过渡年保留未知。

美国新增`CY(y)=.75×MRV实际FY(y)+.25×MRV实际FY(y+1)`，仅在两个相邻财年的MRV科目均已证实时生成。中心使用财年内均匀收款；次财年权重`.15/.25/.35`构成共同期间情景，加原表取整范围。CY2019／2020／2023分别USD1,609.25m／878.5m／2,305.25m；历史国籍、用途保持UNK／未细分类别，`quantity=null`，现金金额不充作申请量。r8以GovInfo BUDGET-2024-DB／2025-DB的Outlays工作簿明确账户571350、名称及actual列，补证FY2022并生成CY2021／2022控制USD1,030.5m／1,788m。旧PDF的泛称offsetting receipts未直接作依据；重组账户FY2019以前的0也未当作真实零收入。

加拿大六项互斥收入采用Public Accounts三财年实际科目：FY2023–24、FY2024–25、FY2025–26。`CY2024=.25×FY2023–24+.75×FY2024–25`，`CY2025=.25×FY2024–25+.75×FY2025–26`，中心假设为财年内均匀确认收入。旧单人TRV“申请量×100”及旧申请活动量桥接已被替换。原文`Multiple entry`科目与家庭封顶科目分别保留；未另列的single-entry收入不构造残差。Programme总收入用于对账，不加到细项金额上。

`history_expansion`补日本2011–2023五组互斥用途与同期费率、韩国2020–2023签发费用情景；日本多次签子集不重复相加，2012留学11件源内差异保留。`spatial_expansion_v2`补阿塞拜疆2022–2024实际签发国家费值、2025运行率情景、纳米比亚2025实收期间桥接。后两者2025数量为null，不据运行率生成每次申请费用。

`temporal_expansion_v2`新增澳大利亚2011–2023签证申请费真实收入的相邻财年桥接及美国2021／2022 MRV补证。`uk_history_v2`从官方季度国籍申请量与当期法定收费建立2013–2018访客／学习模型，保留签证期限结构情景及中国两年访客方案的适用日期。`africa_expansion_v3`与`asia_expansion_v3`的新增科目逐项保留收款范围：外交部子集或东非联签留存额不扩称全国所有签证收入；格鲁吉亚已签发标准费值不写作财政实收；斐济最近财年运行率不写作自然年实际收款。

申请、收费事件、决定、签发、拒签、到达、入境分别编码。`quantity_basis`决定数量含义，不能跨费类合计为申请人数。申请收费且拒签不退与签发后收费须按相应事件处理；多年签不能按每次入境重复收全价。

原币使用ISO代码。人民币换算采用Fed G.5A年均交叉价：`原币金额×原币usd_per_unit÷CNY的usd_per_unit`。2024 USD/CNY为7.1957，2025为7.1875。展示换算不表示逐笔结算价。

主账包含建模的政府签证申请／签发及许可费用；IHS、SEVIS、生物识别、IVL、移民征费、旅行授权、保险、私人服务等不纳入。澳洲总VAC含境内申请；加拿大工作科目含续签／开放许可相关费，范围随模型保留。个人完整账单只作下钻，不乘全体人数后加到主账。

## 5. 中心、范围与缺失

工作中心按透明参数选择。官方输入经分配、平移或行为参数转换后仍为估算；中国和土耳其等弱识别部分明确为工作情景，不称官方实收或已经识别的最佳点估计。

边的`lower_cny/upper_cny`是分项边际敏感性包络。它们可能来自不同国籍分配、交叉结构或负相关余项，不能直接相加称为联合范围。国家流入采用`destination_ranges`的共同参数端点；全球采用`annual_ranges`。美国和澳洲实际总账校准的分配变化不改变总额；日本使用联合可行的多次签边界；申根共同评估国籍、收款成员和日期对应的费率情景；中国印度分项与余项共同受来华总量约束。

加拿大各费用科目共同使用前财年权重`w=.15/.25/.35`及互补`1-w`。`destination_ranges`取完整共同情景端点，不相加国别份额的边际区间；改变来源代理份额只重新分配加拿大已建模收入。这是时点敏感性，不是置信区间，也不覆盖未建模费用。

国家流出范围沿各已归属边的边际包络求和，是保守外包络；差额范围由流入下端减流出上端、流入上端减流出下端得到。它不覆盖未建模国家及无法分配至该国的支出，也不带概率含义。范围跨0时不确定收付方向。申根地区仅展示中心，未制作地区联合范围。筛选子类别不自动继承全类别总账约束。

原件不同表之间的冲突分别保存，不用校准隐藏。2013申根捷克逐领馆646,719／另表649,470，瑞士512,797／475,171；逐行总额与明细表自身总行相等。采用明细的当年两收款方全部路线均在`notes`与`parameters.source_summary_conflict`记录数量差、来源ID、单元格和采用口径，独立记录见`data/research/time_space/source_conflicts.json`。该年不声称跨表总量复现。

明确免费0保留费用边。没有边表示未识别，不表示免费；余额表为了空和与全球守恒保留记账0，但必须结合`inflow/outflow_available`和边数解释；界面相应显示未识别。矩阵缺格为未知，对角线为不适用。

主要未量化范围：沙特；除德国标准费值外的申根长期签；俄罗斯纸签；泰国2023–2025、马来西亚、新加坡除所列中国短访外的费用。韩国、越南已纳入金额，来源未分配；澳洲、加拿大工作、印度、土耳其和中国等也存在大额未知来源。完整范围见`flow_meta.model_scope`和各模型。

## 7. 工作台索引与覆盖契约

`index.records`按`[year,originEntityIndex,destinationEntityIndex,groupIndex,amount_cny,rowCount,zeroCount]`压缩。它是绘图索引，不能把每格当成独立观测。`chunks/{receiver}-{year}.json.gz`保留全部模型分项，`full-data.json.gz`额外包含原始观测、全球底册、覆盖底册。HTTP与单文件从同一生成物读取。

绘图类别为visitor、student、work、family、other、unclassified。`category_detail_status=unclassified`及全年未拆用途总额映射到unclassified，原`visa_group`保留在分项中。Other指已识别的其他类别；图形“其余国家”是显示聚合，与类别及未知国籍无关。

`coverage_inventory`每年每国每类别分别记录`fee_known,fee_current_snapshot_known,quantity_known,amount_known,nationality_known,status,source_ids,notes`。历史费率需生效期证据；仅抓取到当前页面时为current_fee_only，不自动追认历史适用。申根共同短期费率继承给成员，不能继承成长期类别已知。无历史费率但有模型金额时可同时出现amount_known=true与fee_known=false。

`flowScope=internal`只纳入两端均在选集的费用；connected纳入任一端在选集的费用。集合内部、外部已知流入、外部流出、未知来源流入分别统计；unknown并非一个可选择国家。任意筛选不制作无依据的联合区间。比较图国家总账与当前图范围分别标明。

主汇率来自Fed，新增IDR、LKR、QAR、ZAR等采用各区域包明确原件及方法，统一`usd_per_unit`方向；固定汇率和相邻年假设单列，不冒充市场年均。原币费用、汇率引用、期间桥接参数均保留。

## 8. 国家背景与不完整期间

`app/data/context/{code}.json.gz`按国家保存序列，索引`countryContext`登记文件、序列和期间覆盖。当前200辖区、1,018序列、195,045点。单文件将同一gzip编码嵌入`__VISA_CONTEXT__`，file://读取不产生HTTP请求。

每个点保留`observation_id,source_id,source_locator,value,unit,year,period_start,period_end,source_status,bound_type,lower_inclusive,upper_inclusive,quality_issue`等。`strict_lower_floor`显示“>”，`approximate_count`显示“≈”；无明确截止日的记录不进入时间图。财年未完结保留`partial_fiscal_year`，不得补作完整年度。背景选择不改变费用主年份。

`domain`区分mobility、visa_activity、document_activity、rate，`metric`保留具体统计事件。国籍、通常居住地、出生国、递交地、出境目的地由`origin_basis/flow_direction`明确。EU27不展示为申根。缺失单元格保存缺失状态，不产生数值点。

模型输入资格逐序列／期间识别；旅游和边境数量不可代替收费事件。新西兰决定量只有与金额模型实际使用的完整财年匹配时才可标注条件模型输入。背景系列CSV保留精确期间、单位、来源、原值状态和上下界，图中下限点仅作相应下限显示。

完整JSON下载直接解压冻结gzip为字节文件，不建立数十万条记录的JavaScript对象图，也不再次JSON.stringify。导出应与gzip解压原文逐字节一致。


## 9. r11替换、来源身份与背景伙伴

印尼全国账户425212与425221替换旧VOA模型，混合425224未拆部分另留缺口；冈比亚1422177实际与预算分期，否定审计意见及源表冲突保留；塞浦路斯来源明确`archive_kind=fact_excerpt`及`original_downloaded=false`。尼泊尔14228财政实收原期保留，主金额使用独立自然年桥接／代理候选；26条旧正额游客情景被替换，CHN／IND四条明确零费边保留。所有新全国收入的付款国籍保持UNK、匹配数量为null。
