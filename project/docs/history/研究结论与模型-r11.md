# 签证费用进出：研究结论与模型 r11

研究更新：2026-11-17。统一数据版本：`2026.11.17-r11`，工作台`4.5.2`。本报告以[费用分项账](../../data/processed/flows.json)、[国家进出账](../../data/processed/country_balances.json)和[构建元数据](../../data/processed/flow_meta.json)为准；[r3原报告](../../docs/history/研究结论与模型-r3.md)原样归档，[r7原报告](../../docs/history/研究结论与模型-r7.md)保留历史版本；[r8原报告](history/研究结论与模型-r8.md)与[r9原报告](history/研究结论与模型-r9.md)保存此前版本。当前r11已公开部署，线上验证与提交见部署清单。

本项目追踪申请人向哪个政府付款、政府从哪些申请人收款。每个国家的进、出与差额从同一组费用边汇总。r11在既有历史模型上补入印尼、冈比亚、塞浦路斯、尼泊尔和印度签证收入，采用澳大利亚完整FY2025/26，并扩展可交互签证背景。

当前含 **80,443条费用分项、129个模型、618条来源登记、465,528条来源观察**。较r9增加102条来源、27,981条观察和4个模型；新实收替换旧情景后费用行净增3条。费用主年份2011–2025，250国家／辖区底册；人口背景3,227条另存。可展示背景覆盖200辖区、1,018条序列、195,045个点，部分月度期间至2026年9月。观察包含原始单元格和派生，金额覆盖由期间、费用范围和证据决定。

本项目遵循一个中国原则，统一使用中国香港、中国澳门、中国台湾；CHN显示中国大陆统计口径。来源原始名称保留用于追溯。

## 1. 进、出与未知来源

`F(A→B)`表示A国申请人为取得B国签证而向B政府支付的、在指定期间及费用范围内的一笔费用。A是付款人归属，B是收款政府；签证中心代收地、递交地、居民地和出生地分别保留。

| 指标 | 定义 | 使用含义 |
|---|---|---|
| 流出 `Out(A)` | `ΣB F(A→B)` | 本国申请人向外国政府付出的费用 |
| 流入 `In(A)` | `ΣB F(B→A)` | 本国政府收到的申请费用 |
| 收付差额 | `In(A)−Out(A)` | 同一费用范围内，两侧的差 |
| 双边流向 | `F(A→B)`与`F(B→A)` | 两个方向分别保留，缺失方向留作未识别 |
| 网络规模 | 每条费用边只计一次 | 完整边集合满足`ΣIn＝ΣOut`、`Σ差额＝0` |

付款国籍缺失的金额进入`UNK→收款政府`：它计入该政府的流入，也计入未知来源的流出。`UNK`保存可识别收入的归属缺口；它不按游客份额自动分给某国。工作台将未知标签汇入灰色节点，原始标签仍能下钻。守恒说明同一笔钱在两端一致入账，覆盖程度由目的地、类别、期间及证据状态另外衡量。国家流出对应申请人支出，收付差额对应覆盖网络内的收付关系。

申根底层按收款政府保存费用边，界面统一合并为申根；成员国与申根汇总只选择一层进入同一总额。筛选若同时涉及网络内外对手方，边的来源与去向仍沿原始记录追溯。

## 10. 国家摘要、事件均额与人口折算

国家摘要从同一组费用边生成收到、付出、主要对手方、未知归属份额及可比数量均额，见[国家摘要产物](../../data/processed/country_profiles.json)。申根按工作台统一成员集合合并，成员之间的费用在合并图内形成自连边时不显示；底层国家进出账保留原始收款政府。

费用均额按数量口径分别计算：模型申请、估算付费事件、签发、结案及其他已定义模型事件各用自己的费用分子和数量分母。申请次数允许同一人重复申请；附加费事件不与主申请重复相加为独立人数。入境量、旅行次数、国籍分配代理量和无数量的实收控制不进入“每次申请”分母。摘要优先选择覆盖费用金额最大的可比事件组，同时保存它占该方向总金额的份额，其他口径不共用分母。日本免收签发保留在签发分母内；阿塞拜疆2025运行率和纳米比亚跨年数量不写成自然年真实申请人数。

人口来自世界银行WDI的`SP.POP.TOTL`同年记录，中国台湾另用2024／2025年末户籍人口并明示口径。中国大陆、中国香港、中国澳门保留WDI统计区域分项；全部展示名称遵循前述中国名称规则。人口只取同年，缺年不前移或回填。申根人口为工作台统一29成员集合的同年人口相加，集合中任何成员缺数时不提供合计。人口金额比为`当前覆盖费用÷同年人口`，用于比较规模。来源及原口径见[人口上下文](../../data/research/demographic_context/population.json)。

例如中国大陆2025年覆盖网络内流出62.13亿元，按同年1,406,585,000总人口折算约4.42元／人。摘要中最大可比事件组为每次估算付费约739.07元，该组对应流出金额的31.50%；它的分母是估算付费事件。人口折算与事件均额在摘要中分别标注为“按人口折合”与具体事件名称。

## 11. 互斥入账与更新规则

1. **同一笔政府费只计一次。** 代收后转交、原账总额及其分配费用边不重复加总；服务中心自留费、保险及银行费按真实收款方另列。
2. **按收费项目划分金额。** 工作许可处理费与开放工签附加费可相加；它们对应的付款事件数不能加成申请人数。财政总账、子项目和原有情景的替换范围随模型登记。
3. **按数量指标使用证据。** 申请、签发、决定、入境、认定书及旅行复用各自保留；拒签费用只有在匹配收费事件、退款及期间后计入。免签节省是固定旅行量与需新办比例下的反事实情景，独立于实际费用网络。
4. **由原始科目到费用边，再到国家账。** 新证据先确定期间、币种、归属和已有重叠项，再离线生成互斥边；国家余额、矩阵、界面和导出读取同一产物。原件路径、SHA、提取定位与参数随记录保存。

最终数据与守恒检查见[统一检查](../../data/processed/checks.json)；每项金额可沿`source_ids`、`observation_ids`和`method_id`回到原件、提取观察和公式。2026已发布的政策或统计按其真实日期留存，2011—2025图表使用相应历史版本。
