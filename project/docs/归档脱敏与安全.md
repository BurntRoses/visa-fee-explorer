# 第三方网页归档清理 · 2026-11-18

GitHub 在阿联酋 GDRFA 单次旅游签页面归档、摩洛哥旅游手续页面归档中报告两个 Google API key。前者位于 Google Maps JavaScript（含 Places）脚本链接，后者位于 HTML 注释。应用没有配置或调用这些 key。额外两份未进入网站来源索引的本地网页也含同类字符串，已清理。

四份本地快照用占位符替换 key，加入 CSP 阻止脚本、外部请求和表单，保留签证事实与原始网页地址。R12 来源表和归档清单记录新哈希；发布程序对拟公开的文本归档检测 Google browser key 格式。GitHub 已把十个历史提交的公开分支和 R11 标签换成脱敏历史；R11 来源第 003、005 卷与对应清单也已更新。旧的本地交付容器在可恢复、去重并校验的历史增量归档写成后移除。

清理不等于吊销。Google Cloud 凭据只能由所属项目管理员吊销；本项目没有用到这些 key，无需生成替代 key。GitHub 远端仍可返回旧提交对象，需要仓库所有者联系 GitHub Support 清除相关悬空提交和缓存。未确认外部下载副本是否存在。不要把旧提交或旧备份重新推送。
