# 运行与重建

- **在线**：[GitHub Pages](https://burntroses.github.io/visa-fee-explorer/) 是固定公开入口。[来源 Release](https://github.com/BurntRoses/visa-fee-explorer/releases/tag/source-archives-2026.11.18-r12) 提供离线 HTML、完整 JSON、来源分卷与校验值。
- **离线**：双击 Release 中的 `visa-fee-workbench-4.8.0.html`，图表和明细无需联网。要离线阅读原始文件，先把 HTML 放进一个 `app/` 目录，再将六个来源分卷解压到其上一级，使 `data/raw/` 与 `app/` 同级。
- **预览已发布版本**：在仓库根目录执行 `python3 -m http.server 18765 --bind 127.0.0.1 --directory site`，打开 [本地入口](http://127.0.0.1:18765/)。
- **从公开数据重建前端**：使用 Node.js、pnpm 和 Python 3。在仓库根目录运行 `pnpm --dir project/app/workbench install --frozen-lockfile`，再运行 `python3 project/scripts/build_app.py --published`。该模式以 `site/app/data/` 的 R12 数据为输入，将产物写入 `project/app/`，不依赖原工作目录。
- **复查统计**：以 Release 的完整 JSON 和来源文件为准。研究与估算脚本保留在 `project/scripts/`；`rebuild_all.py` 是研究阶段的记录，需要未随公开版发布的中间底稿，不能直接从这个仓库完整重跑。
- **发布**：GitHub Actions 将 `main` 中的 `site/` 发布到 Pages。先读取最新年度及趋势摘要，其余年份、国家背景和费用证据按需加载。

热图行是付款国籍，列是收款政府，两轴使用同一排序。反向路线按各自金额绘制。绿色比较独立的双边路线，灰蓝色表示其余国家的汇总；国籍未分配单列，并保留在费用总额中。
