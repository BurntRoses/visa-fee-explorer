# 运行、复算与发布

- **离线使用**：双击 `app/签证这笔钱-离线版.html`。保留 `app` 与 `data` 的相对路径，本地来源链接即可打开。无需安装或联网。
- **预览网站**：项目根执行 `python3 -m http.server 18765 --bind 127.0.0.1`，打开 [HTTP 本地入口](http://127.0.0.1:18765/app/)。
- **复算**：需 Python 3.12、Node.js、pnpm。创建 `.research-venv`，安装 `requirements.txt`；在 `app/workbench` 执行 `pnpm install --frozen-lockfile`，再回到项目根执行 `.research-venv/bin/python scripts/rebuild_all.py`。依赖就位后，重建从冻结原件读取，默认无需网络。
- **数据路径**：`data/raw` 是原件或标明的脱敏快照，`data/research` 是提取与留存基线，`data/estimates` 是原币模型，`data/processed` 是统一费用账和来源表。可视化源码在 `app/workbench/src`。
- **发布**：`scripts/prepare_github_pages.py` 准备 Pages 文件及 Release 资源计划；先上传来源资产，再发布 Pages。检查脚本 `verify_source_release.py`、`verify_deployment.py` 会下载并核对线上产物。同一数据版本只更新界面时，使用 `--preserve-source-placement` 加上当前发布的来源清单路径，可保持归档位置及文件哈希。详见 [R11 的完整操作记录](history/运行与更新-r11.md)及 [R12 验收](validation/验收说明.md)。

尽量沿用来源编号和原始统计口径。发现新候选来源时，先检查期别、收费事件、费种和已有入账范围。任何包含第三方凭据的归档必须先脱敏，更新 SHA-256，并验证公开文件与压缩包；[安全记录](归档脱敏与安全.md)说明 R11 的处理和剩余事项。

UI 4.7.0 首屏只读取 boot 分片，国家背景、来源和模型明细按需载入。界面代码更新但数据版本不变时，使用 `scripts/prepare_github_pages.py --preserve-source-placement <当前 source-archives.json>`，避免重新移动相同来源资产。
