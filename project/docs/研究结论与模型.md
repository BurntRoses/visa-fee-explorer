# 签证费用研究与模型 · R12

数据冻结于 2026-11-18，版本 `2026.11.18-r12`。历史方法、其它国家财务和 ± 情景见 [R11 完整模型](history/研究结论与模型-r11.md)及 [数据规范](数据规范.md)，其中版本统计以本页更新为准。

费用网络按付款国籍 → 收款政府建账。同一费用只入账一次，未知付款国籍归未分配。各国收付使用同一组边，只有核对过口径的匹配数量可计算均额。当前范围不包括 ETA、私人签证中心服务费、保险等。日期范围 2011–2025，各年度覆盖面不同；有正额记录也不代表收款方的所有签证费已知。

Eurostat `migr_resfirst` 增加 84,662 个报告辖区 × 年份 × 国籍或用途观测，含来源质量标记与缺值；其中 82,783 个总用途数值已与同一官方库的另一 API 查询核对。按国籍全用途与按用途全体国籍是重叠切片。许可可能包括此前许可失效至少六个月后再办的情况，与入境签证分开。[Eurostat 数据表](https://ec.europa.eu/eurostat/databrowser/view/migr_resfirst/default/table?lang=en)。

加拿大 IRCC 两份原工作簿增加 17,962 个 2023-01–2026-09 月度观测，来源业务快照为 2026-10-06。2026-09 全球受理 314,000、处理 357,850，按原表人数口径。1–4 被隐匿，公开的零是零，其余多数按 5 取整。两列指标不是同一队列中的获批率；延长、学习及工作许可并存，不能用作签证缴费分母。[IRCC 受理工作簿](https://www.ircc.canada.ca/opendata-donneesouvertes/data/Open%20Data%20-%20OPS%20TRV%20Intake%20en.xlsx) · [IRCC 处理工作簿](https://www.ircc.canada.ca/opendata-donneesouvertes/data/Open%20Data%20-%20OPS%20TR%20Processed%20en.xlsx)。

原始来源定位见 [来源登记](../data/processed/sources.csv)，新提取代码为 [背景统计](../scripts/research_r12_public_statistics.py)和[财政模型](../scripts/model_r12_fiscal.py)。法国及斯里兰卡复用此前归档，不重复增加来源登记。尼泊尔、斯里兰卡新增年份使用世界银行年平均本币兑美元与项目统一的人民币年均汇率。

未覆盖的范围仍包括不少国家的纸质签、境内变更、私营收费、个别政府未公开的签证叶科目、以及无法与财政收款匹配的付费数量。遇到这些情况，保留已证实口径和缺口，不从入境量生成收费估算。当前界面可按辖区及类型查看覆盖底册，并导出 CSV。
