# 签证费用流向工作台

[使用工作台](https://burntroses.github.io/visa-fee-explorer/) · [下载数据和来源](https://github.com/BurntRoses/visa-fee-explorer/releases/tag/source-archives-2026.11.18-r12) · [查看数据口径](project/docs/研究结论与模型.md)

**最终发布：R12 数据 / 4.8.0 界面。** 查看 2011–2025 年签证费用从申请人国籍流向收款政府的记录。支持全球、自选和单国视图，图表可缩放，点选路线可查金额、估算依据和来源。

金额区分公开实收与模型估算；各年覆盖不同，付款国籍未知的金额单列。旅行与出入境统计独立于费用账。第三方资料按各来源的条款使用；[归档说明](project/docs/归档脱敏与安全.md)注明了脱敏和公开阅读副本的处理方式。
