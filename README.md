# 签证费用

分享地址：https://burntroses.github.io/visa-fee-explorer/

多选国家，查看申请人国籍到收款政府的签证费用流。支持环形、单国、桑基、比较和热图，2011–2025时间轴、来源下钻与导出。

数据版本`2026.11.16-r6`，界面`4.3.0`。包含306份项目引用的公开来源原件。历史年度、各目的地与签证类别覆盖不同，模型口径和参数在费用明细保留。

`site/`是静态网站；主入口与`app/`入口均可用。应用保留按需加载的压缩证据和完整JSON，原件在`site/data/raw/`。离线文件为`site/app/签证这笔钱-离线版.html`。

推送到`main`后由GitHub Actions发布至Pages。完整研究工程保留在本地项目，本仓库存放核验后的发布产物。
