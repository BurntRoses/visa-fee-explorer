地　点：北京，国家移民管理局　　　　　　时　间：2024年1月18日
主持人：张宁　国家移民管理局新闻发言人 综合司副司长
国家移民管理局新闻发布会

1月18日，国家移民管理局召开例行新闻发布会，通报2023年移民管理工作主要数据和工作情况。发布会由国家移民管理局新闻发言人、综合司副司长张宁介绍有关情况并回答记者提问。

国家移民管理局新闻发布会

[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　女士们、先生们，媒体朋友们：大家上午好。欢迎出席国家移民管理局新闻发布会！新年伊始，很高兴和大家在线上相聚。今天新闻发布会的主题是通报2023年移民管理主要数据和工作情况，并回答大家的提问。

　　首先，我向大家通报2023年移民管理主要数据和工作情况。

　　2023年是全面贯彻党的二十大精神的开局之年，全国移民管理机构坚决贯彻党中央、国务院决策部署，认真落实统筹国内国际两个大局、统筹高质量发展和高水平安全对移民管理工作的要求，坚持把学习贯彻习近平新时代中国特色社会主义思想主题教育贯穿全年，充分发挥职能作用，全力以赴防风险、保安全、护稳定、促发展，有力维护国家政治安全、国门边境稳定和出入境管理秩序，有力服务促进高水平开放高质量发展，顺利完成了全年各项工作任务。全年累计查验出入境人员4.24亿人次，同比上升266.5%；其中内地居民2.06亿人次、港澳台居民1.83亿人次、外国人3547.8万人次，同比分别上升218.7%、292.8%、693.1%。全年累计查验出入境交通运输工具2346.1万架（列、艘、辆）次，同比上升143.4%；其中飞机54.1万架次、列车9.1万列次、船舶40.4万艘次、机动车辆2242.5万辆次，同比分别上升108.5%、16.8%、28.7%、149.5%。

　　2023年，全国移民管理机构坚持把捍卫国家政治安全置于首位，先后高标准完成中国—中亚峰会、第三届"一带一路"国际合作高峰论坛、成都大运会、杭州亚运会等重大活动移民管理安保任务。统筹推进严厉打击妨害国（边）境管理犯罪"獴猎"行动-2023、"三非"外国人治理等专项行动，坚决筑牢国门边境安全稳定屏障，坚决维护国家主权、安全和发展利益。全年共侦办妨害国（边）境管理犯罪案件5.8万余起，抓获犯罪嫌疑人10.9万余人，打掉犯罪团伙2463个，捣毁中转窝点1517个。其中，挂牌督办重特大案件232起，抓获犯罪嫌疑人5556人，抓获"捕蛇"目标逃犯596名。全年依法查处非法入境、非法居留、非法就业外国人6.5万人，严格依照法律规定分别给予警告、罚款、行政拘留、限期出境等处罚，对其中符合法定情形的2.6万人执行遣送出境。严密防范打击涉赌涉诈等跨境违法犯罪，口岸查获各类偷渡人员3.5万人次，依法查缉拦截涉赌诈等跨境违法犯罪人员3.2万人次。全年查缴枪爆物品8万余件，缉获各类毒品8.5吨、制毒物品949.3吨、走私货物案值7.6亿余元。

　　2023年，全国移民管理机构始终坚持人民利益至上，不断深化移民管理服务改革和政策制度创新，主动对接国家重大发展战略和区域发展战略，出台一批支持自由贸易试验区建设、海南自由贸易港建设、粤港澳大湾区建设、福建两岸融合发展示范区建设的移民管理政策措施，全力服务促进高水平对外开放，服务保障高质量发展。全面恢复受理审批中国公民出入境证件、口岸客运通关、外国人区域免签及口岸签证、内地居民赴港澳团队旅游签注"全国通办"等政策；推出内地居民赴港澳地区探亲、工作、学习等签注"全国通办"新政，在粤港澳大湾区内地城市试点实施往来港澳人才签注政策，对受疫情影响的港澳居民回乡证有效期实行延期；会同相关部门多批次调整外国人入境政策，优化区域性入境免签、过境免签和口岸签证政策，下调签证收费标准，将挪威增列为过境免签适用国家，启用新版外国人永久居留身份证——"五星卡"，积极会同有关部门持续推动"五星卡"社会便利化应用，有力促进中外人员正常往来和产业链供应链稳定畅通。全年共签发普通护照1842.8万本，往来港澳台通行证件及签注8609万本件、外国人签证证件170.5万本次，同比分别上升1625.4%、1318%、158.3%；480万余人次内地居民享受赴港澳签注"全国通办"便利，节省交通费88.8亿元，1.9万名粤港澳大湾区内地高层次专业人才获批往来港澳人才签注，人才、技术等要素高效有序流动，440万余人次港澳居民持延期证件顺畅通关，1200万人次在内地便捷办证办事。提档升级移民管理政务服务，国家移民管理局政务服务平台共为中外出入境人员提供查询等政务服务9095万人次，深化出入境证件便利化应用，为港澳居民、华侨和外国人免费提供身份核验服务2718万人次；12367移民管理政务服务热线接处全球来电580万通，平均满意率99.31%。

　　一年来移民管理工作取得的成绩，根本在于以习近平同志为核心的党中央坚强领导，在于习近平新时代中国特色社会主义思想的科学指引，得益于社会各界和广大出入境人员的理解支持，也凝聚着移民管理机构广大民警职工的团结奋斗、奉献牺牲。

　　2023年，全国移民管理机构6个集体被命名为第十批全国民族团结进步示范单位，14个集体被命名为"第21届全国青年文明号"，2个边境派出所获评第三批全国"枫桥式公安派出所"，10名同志获评第二届十大国门卫士，8487名民警获颁戍守边疆金、银、铜质纪念章，120余个集体、300余名个人荣获省部级以上表彰或二等功以上奖励。12名民辅警牺牲殉职，77名民辅警因公负伤，用鲜血和生命践行了"人民公安为人民"的庄严承诺。

　　新的一年，我们将忠实履行好党和人民赋予的新时代移民管理使命任务，接续奋斗、砥砺前行，全面推进移民管理工作现代化，为推进强国建设、民族复兴伟业发挥更大更好的作用！

　　以上就是我今天要通报的内容。下面，欢迎各位记者围绕今天发布会的主题，就感兴趣的问题进行提问。提问之前请通报一下所在媒体的名称。

[ 中国日报记者 ]：

　　1月11日，在国新办新闻发布会上，国家移民管理局公布了便利外籍人员来华5项措施，受到社会高度关注，请问措施出台后，国家移民管理局将如何确保这些政策措施尽快落到实处?
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　谢谢您的提问。这次便利外籍人员来华5项措施出台后，国家移民管理局已部署全国移民管理机构抓细抓实举措落地，及时研究解决政策措施实施中遇到的问题，确保取得实效。主要从四个方面推进。一是细化任务分工。指导各级结合实际，细化制定实施方案，逐项明确具体任务和要求，上下联动确保各项政策措施落地见效。二是加强政策宣介。指导各级进一步加强对外宣介、政策解读、专题培训等有关工作，重点是面向本地区在华外籍人员、涉外企业单位，不断扩大政策知晓面，有效释放政策红利。三是强化跟踪问效。加大调查研究、检查督促力度，加强对政策实施的跟踪分析、督促检查，全面掌握落实情况和实施效果，及时发现并协调解决实施中遇到的困难和问题，确保中外企业群众有实实在在的获得感。四是做好总结评估。将适时对政策落实情况进行总结评估，及时总结提炼经验做法，形成可复制、可推广的实践创新成果，不断提升外国人来华在华服务管理工作质效。

[ 中国新闻社记者 ]：

　　我注意到，刚刚公布的2023年内地与港澳、大陆与台湾间人员往来数量呈快速增长的特点，能介绍一下相关情况吗？
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　谢谢您的提问。2023年以来，国家移民管理局认真贯彻落实党中央决策部署，充分发挥出入境管理职能作用，实施制度型开放举措，服务促进内地与港澳人员交流交往，积极服务两岸融合发展。在内地与港澳人员往来方面，受出入境改革创新措施推动，2023年内地与港澳间往来人数稳步回升，内地赴港澳以旅游人员为主，同时呈现出目的多样化、人群多元化趋势，人才、技术等要素高效便捷流动，为内地和港澳经济快速复苏注入活力动能。随着口岸快捷通关，"港车北上""澳车北上"等政策的落地实施，从广东省口岸入境的港澳居民人数明显增多，占入境总人数的九成以上，充分体现了粤港澳大湾区及前海深港合作区、横琴粤澳深度合作区等国家重大战略的加速发展。在两岸人员往来方面，台胞来大陆人数快速恢复，较2022年上涨7.4倍。为深入贯彻落实《中共中央 国务院关于支持福建探索海峡两岸融合发展新路 建设两岸融合发展示范区的意见》，我局推出10项出入境政策措施于今年正式实施，实施首日在福建高校任教的台胞就已经获发定居证。政策实施十余天时间，已经有600余名台胞享受到来往大陆通行证件"网上办""口岸办"等便利措施，1万余人次台胞通过福建口岸快捷通道顺畅通关。下一步，我局将充分发挥职能优势，持续创新出入境管理服务，促进港澳更好融入国家发展大局，助力两岸各领域融合发展。

[ 总台央广记者 ]：

　　刚才通报中提到，2023年国家移民管理局打击妨害国（边）境管理犯罪战果丰硕。新的一年还将有哪些新的部署和行动？
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　谢谢您的提问。2024年，国家移民管理局将深入贯彻落实党中央关于打击跨境犯罪重要批示指示精神，按照公安部部署要求，会同各警种各部门，指挥协调全国公安机关和移民管理机构，持续严厉打击各类妨害国（边）境管理犯罪，全力捍卫国家安全，坚决维护口岸边境稳定和正常出入境管理秩序。一是持续强化重点打击。部署开展深入打击妨害国（边）境管理犯罪"獴猎"行动-2024，严厉打击陆地边境偷渡、口岸非法出入境活动和涉出入境证件类犯罪等突出违法犯罪活动，持续开展"捕蛇"追逃行动，保持严打高压态势。二是着力加强数据支撑。指导各地各单位加强线索搜集、分析研判和大数据综合应用，提升对妨害国（边）境管理犯罪活动的动态感知和精准打击能力。三是全面强化综合治理。推动市、县两级将"反偷渡"工作纳入基层治理和"平安建设"考核范畴，持续深化"重点地区、重点领域、重点人员"集中整治，大力开展法律宣传，广泛动员群众，提升妨害国（边）境管理犯罪源头综合治理成效。四是持续深化跨境执法合作。持续深化与重点国家和地区的执法合作，完善跨境抓捕遣返、刑事司法协助等合作机制，不断拓宽合作方式，为推进非法移民问题全球治理贡献中国方案、中国智慧。

[ 人民日报记者 ]：

　　1月11日，国家移民管理局出台5项便利外籍人员来华措施，请问在不断优化放宽外籍人员来华在华相关出入境政策措施的同时，如何保障出入境秩序安全有序？
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　谢谢您的提问。随着中国不断扩大开放，越来越多外国人来华工作、学习和生活，其中绝大多数外国人遵守中国法律，推动了中外交流合作、增进了中外友好友谊。但是，也有少数外国人从事"三非"等违法犯罪活动，干扰破坏了正常移民和出入境管理秩序。移民管理机构始终坚持统筹高质量发展和高水平安全，在保障促进中外人员往来和中外交流合作、依法维护来华外国人合法权益的同时，坚持法律面前人人平等，坚持严格、公正、规范、文明执法，依法查处非法入境、非法就业、非法居留等违反《中华人民共和国出境入境管理法》行为，依法打击妨害国（边）境管理秩序的违法犯罪活动。

　　2023年以来，全国公安机关共查处"三非"外国人6.56万人次，对其中情节严重、符合法定情形的依法遣送出境，并不断健全完善常态长效治理制度机制，维护正常的移民和出入境管理秩序。

[ 香港南华早报记者 ]：

　　请问目前在华常驻外籍人士总数的数据如何？同比以及相较于疫情前2019年底时，数字上有何变化？对于2024年外籍人士入境人数有何具体预期？
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　2023年，全国移民管理机构共为在华常住外国人签发各类居留证件71.1万人次，在华常住外国人已恢复至2019年底的85%。近日，国家移民管理局再次公布施行多项便利外籍人员来华的政策措施，包括放宽申办口岸签证条件、在北京首都机场等枢纽空港口岸24小时直接过境免办查验手续、在华外籍人员可就近办理签证延期换发补发、简化签证证件申办材料等，进一步拓宽外国人来华渠道，为外国人在华工作、学习、生活提供高效便捷的移民管理服务。

　　相信随着我国经济社会持续恢复回升向好，对外开放水平不断扩大，国家移民管理局协同有关部门实施一系列促进中外人员往来的便利措施，来华外国人数量将持续稳步提升。
[ 国家移民管理局新闻发言人 综合司副司长 张宁 ]：

　　因为时间关系，我们的提问就到这里。非常感谢大家出席今天的新闻发布会。今天是腊月初八，老话常说"过了腊八就是年"。在这里，提前给各位媒体记者朋友、给广大出入境旅客和关心支持移民管理工作的海内外各界友人拜个早年，祝大家新春快乐，工作顺利，身体健康，万事如意！今天的发布会到此结束。各位记者朋友如果有进一步的采访需求，请与国家移民管理局新闻发言人办公室联系。我们下次再见。谢谢。
