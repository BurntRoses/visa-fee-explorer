国家移民管理局网络新闻发布会

1月27日，国家移民管理局召开网络新闻发布会，通报2021年移民管理工作主要数据及成效。发布会由国家移民管理局新闻发言人、政策法规司司长陈杰介绍有关情况并回答记者提问。

国家移民管理局网络新闻发布会

[ 国家移民管理局新闻发言人　政策法规司司长　陈杰 ]：

媒体朋友们，女士们、先生们：大家上午好。欢迎出席国家移民管理局新闻发布会！很高兴和大家再次在线上相聚。根据安排，今天由我向大家通报2021年国家移民管理主要数据和工作情况，并回答记者的提问。
首先，我向大家通报2021年移民管理主要数据和工作情况。
2021年是我们党和国家历史上具有里程碑意义的一年。我国经济发展和疫情防控保持全球领先地位，国家战略科技力量加快壮大，产业链韧性得到提升，改革开放向纵深推进。国家移民管理机构在认真做好常态化疫情防控、严防境外疫情输入的前提下，充分发挥职能作用，保障中外交流交往安全有序，积极服务构建以国内大循环为主体、国内国际双循环相互促进的新发展格局。全年累计查验出入境交通运输工具1409.4万架（列、艘、辆）次，其中货运飞机22.8万架次，同比增长22.8%；货运列车7.2万列次，同比上升3.6%。全年累计查验出入境人员1.28亿人次，同比下降2.8%；其中内地居民出入境7423.4万人次，同比上升6.6%；港澳台居民出入境4897.3万人次，同比上升4.4%。
2021年，国家移民管理局坚决贯彻党中央、国务院决策部署，认真落实统筹发展与安全对移民管理工作的要求，始终将捍卫国家政治安全置于首位，一体推进维护正常出入境秩序、防范境外疫情输入、服务促进高水平开放高质量发展各项工作，各级移民管理机构和广大民警忠诚履职、担当作为、拼搏奉献，顺利完成了全年各项工作任务。
第一，严密防范、严厉打击跨境违法犯罪活动。深入贯彻总体国家安全观，以做好中国共产党成立100周年大庆安保工作为主线，以开展集中打击妨害国（边）境管理犯罪专项斗争、深化"三非"外国人治理等专项行动为牵引，以建立健全全链条管控、立体化防控体系为保障，以增强执法能力、提高执法水平为重点，强化突出问题整治、风险隐患化解、复杂局面应对，坚决维护国家主权、安全、发展利益。全年共侦办妨害国（边）境管理犯罪案件1.96万起，抓获涉案人员9.85万人，其中采取刑事强制措施5.01万人、给予行政处罚4.84万人，同比分别上升139%、256%、265%、247%，平均每天侦破案件50余起、抓获涉案人员200多人。全年依法查处"三非"外国人7.9万人，严格按照法律规定分别给予警告、罚款、行政拘留、限期出境等处罚，对其中4.4万人执行遣送出境，遣返的比例和去年相比上升21%，平均每天遣返100多人。全年缴获各类毒品10.38吨、易制毒化学品626.28吨；查缴各类枪支2598支；查缉走私物品案值3.76亿元。
第二，全面融入、全力服务经济社会发展大局。坚持以人民为中心的发展思想，紧扣完整、准确、全面贯彻新发展理念，服务构建新发展格局，加快推进移民管理理念转变、制度创新、政策优化、措施升级，促进移民管理服务更加高效精准、优质专业。国家移民管理局认真研究贯彻落实国家"十四五"规划和2035年远景目标纲要，紧紧围绕国家重大发展战略制定"十四五"时期移民管理事业发展规划，系统推进深化移民管理改革，加强重点领域和关键环节建设。各地各级移民管理机构全力服务京津冀、长三角、海南自贸港、粤港澳大湾区、浦东新区等区域建设发展规划，精准实施一大批移民管理政策措施，为重点区域发展注入新活力新动能。2021年，我们聚焦为市场主体和人民群众办实事解难题，出台促进航运企业发展新举措16项，在陆地口岸增设"一带一路"专用通道240余条，推动在部分粤港澳陆地口岸实施"合作查验、一次放行"的新型通关模式，实施港澳居民在内地换补发"回乡证"等16项办理出入境证件便利措施，不断优化常态化疫情防控条件下通关环境，全面促进各类发展要素健康流动，全面提升移民管理政务服务科学化、便利化水平。全年验放货运船舶、航班、列车48.4万艘（架、列）次，同比增长8.7%，为企业节约办证时间20.1万小时、节省费用超15亿元；为179.4万符合条件的申请人提供便捷办证服务；为港澳居民、海外华侨持用出入境证件办理社会事务提供身份认证服务3384万人次；通过英文版门户网站和12367服务平台等为中外人员提供多语种政策法律咨询解答106.5万余次，平均满意度97.2%。
第三，持续巩固、全面筑牢疫情外防输入防线。坚决贯彻"外防输入、内防反弹"总策略，坚守战位、坚定抗疫，强化口岸查验、边境堵截，控制非必要跨境人员流动，全方位夯实筑牢防范境外疫情输入的国门边境防线。2021年，继续暂停口岸签证和区域性免签政策，落实从严从紧的入境政策，在保证防疫安全前提下稳妥有序为来华从事经贸、科技等活动及具有紧急人道主义需要的外国人提供必要的入境便利，全年外国人入出境453.1万人次，同比下降65.9%。继续倡导非紧急、非必要不出境，严格审批签发内地居民出入境证件，广大群众充分理解配合，全年共受理审批普通护照63万本，往来港澳台通行证件144万本、签注591万个。进一步改进口岸疫情防控措施，根据陆海空不同类型口岸人员和交通运输工具出入境管理需要，完善与陆地口岸"客停货通"、非接触转运，海港口岸非必要"不登轮不登陆不搭靠"，空港口岸"国际国内隔离、旅客员工分流、货运客运分区"要求相适应的监管和查验措施，严格落实闭环管理。进一步强化边境地区"一线巡控、二线查缉、辖区管控"，夜以继日坚守2.2万公里陆地边境线，对1900多条通外山口、便道和渡口实行全时段巡逻管控，对进出边境地区人员和车辆实行全天候双向检查，在抵边村寨对外来人员和外籍人员实行全覆盖核查。进一步加强与各地各部门联防联控，及时向海关、卫健部门和属地联防联控机制通报高风险地区人员信息，配合开展流调溯源、区域协查，推动实现从"国门"到"家门"闭环管理。
一年来移民管理工作取得的成绩，根本在于以习近平同志为核心的党中央坚强领导，得益于社会各界和广大出入境人员的理解支持，也凝聚着移民管理机构广大民警职工的顽强拼搏、奉献牺牲。2021年，全国移民管理系统共有557个集体和个人荣获二等功以上奖励和省部级以上表彰，涌现出了"公安楷模"柳永清和四川省阿坝州公安局出入境管理支队、云南独龙江边境派出所等一大批先进典型，蔡晓东等7名同志牺牲殉职，49名同志因公负伤，用鲜血和生命践行了"人民公安为人民"的庄严承诺。新的一年，我们将不忘初心、牢记使命，踔厉奋发、笃行不怠，努力以党和人民满意的工作成绩，迎接党的二十大胜利召开。
以上就是我今天要通报的内容。下面，欢迎各位记者围绕今天发布会的主题，就感兴趣的问题进行提问。提问之前请通报一下所在媒体的名称。
[ 新华社记者：]

新冠疫情暴发以来，国家移民管理局施行了从严从紧的出入境政策，坚持非紧急非必要不出境，一些群众反映申办护照等出入境证件比较困难，外国人来华仍有很多限制，请问2022年我国出入境政策会不会进行调整和放松？对于有特殊情况需要出入境的人员有没有相应保障？
[ 国家移民管理局新闻发言人 政策法规司司长 陈杰：]

谢谢新华社记者的提问。为保护中外人员身体健康、生命安全，新冠肺炎疫情暴发以来，国家移民管理局按照国务院联防联控机制统一部署，根据疫情防控需要和各国普遍做法开展境外疫情防输入工作，实施从严从紧的外国人入境政策，倡导非紧急非必要不出境，并根据疫情形势进行科学动态调整，着力防止疫情通过出入境渠道传播，取得了显著的效果。工作中，我们也要求各级移民管理机构具体问题具体分析，在政策执行过程中不搞"一刀切"、避免简单化。目前，对赴境外留学、就业、商务等确有出境需求的人员，对确有需要来华进行经贸、科技活动的人员和具有紧急人道主义原因确需入境的人员，经审核属实后，移民管理机构都会及时签发出入境证件。尤其是对参加国际防疫抗疫以及因为企业复工复产需要出入境的中国公民，各级还会主动提供优先受理审批以及加急办证服务，同时，继续依法为在华外国人办理签证和停居留提供便利，以实际行动支持全球防疫抗疫，助力恢复经济生产。总体而言，相关政策措施和具体安排可以保障必要人员交往通道顺畅，有助于构建健康、安全、有序的中外人员往来秩序。
当前，境外疫情持续蔓延，新的变异毒株正在加速传播，我国面临的外防输入形势依然严峻。疫情防控工作离不开广大出入境人员的支持配合，国家移民管理局再次提醒，当前境外疫情尚在流行，并未得到有效控制，要珍惜国内来之不易的疫情防控成果，严格遵守防疫规定，减少非紧急非必要跨境人员流动。 关于您提到的特殊情况下人员出入境问题，我们已有专门的规定安排满足确有必要出境人员的需要。
[ 澎湃新闻记者：]

您在刚才的通报中提到2021年查处"三非"外国人7.9万人，遣送出境4.4万人次。请问国家移民管理局对查处的"三非"外国人都有哪些处理措施？谢谢。
[ 国家移民管理局新闻发言人 政策法规司司长 陈杰：]

感谢您的提问。国家移民管理机构依法保障在华外国人合法权益，依法防范查处外国人非法入境、非法居留、非法就业活动以及妨害国（边）境管理犯罪行为。对于"三非"外国人，根据《中华人民共和国出境入境管理法》、《中华人民共和国外国人入境出境管理条例》，视违法行为情节，分别给予警告、罚款、行政拘留、限期出境、没收违法所得等行政处罚，对其中违法情节严重的，依法遣送出境或驱逐出境。对于触犯《刑法》，构成组织他人偷越国（边）境等妨害国（边）境管理犯罪的外国人，依法追究刑事责任。广大群众如果发现涉嫌"三非"及妨害国（边）境管理犯罪活动的线索，请及时向当地公安机关举报或拨打国家移民管理机构12367服务热线进行举报，共同维护良好的出入境管理秩序。
[ 人民日报记者：]

冬奥会召开在即，首都国际机场作为北京冬奥会唯一官方入境口岸，请问国家移民管理局在人员入出境通关保障方面，有哪些针对性措施？
[ 国家移民管理局新闻发言人 政策法规司司长 陈杰：]

谢谢您的提问。国家移民管理局高度重视冬奥会人员入出境通关保障工作，部署北京机场等口岸出入境边防检查机关按照"好来快走"的总体要求，全力保障参加冬奥会人员通关更加安全高效、防疫更加严密稳妥。
一是优化通关查验流程。专门制定冬奥会出入境通关服务保障总体方案以及各类子方案，进一步优化涉冬奥人员查验工作流程。加强涉冬奥人员流量预报，提前开展信息核对，根据通关流量动态调配执勤警力，保障涉冬奥人员安全有序快速通关。
二是完善服务保障措施。部署北京和备降机场边防检查机关实行"一专一免"便利通关措施，即开设冬奥边检专用通道、免填外国人入境卡，为涉冬奥人员提供"零等待"查验服务。升级各类查验设施、完善现场标志标识，全力为涉冬奥人员创造良好的通关环境。
三是严格疫情防控。严格落实冬奥防疫管理各项要求，对涉冬奥人员实行专区查验，降低交叉感染风险。加强与冬奥疫情防控部门协调配合，及时互相通报情况，积极配合转运衔接、闭环管理。同时加强内部安全防护，执行相关任务的移民管理民警严格落实"两点一线""隔离监测"等封闭性管理措施，确保闭环内外绝对隔离不交叉，保障冬奥会入出境防疫安全。
[ 凤凰卫视记者：]

刚才通报中提到，国家移民管理局推出了港澳居民来往内地通行证在内地换发补发新政，请问目前实施成效如何？谢谢。
[ 国家移民管理局新闻发言人 政策法规司司长 陈杰：]

谢谢您的提问。为认真贯彻落实中央关于支持港澳融入国家发展大局的重大决策部署，全国公安机关出入境管理部门自2020年10月10日起全面开展港澳居民来往内地通行证换发补发工作，在内地的港澳居民证件过期换发、遗失损毁补发可以向全国任意一个县级以上公安机关出入境管理部门提交申请，在申请条件、申办手续、审批要求不变的基础上享受就近申办、一次办结、在线服务等便利。新政实施一年多来，有效解决在内地的港澳居民因疫情不便往返办理证件的现实困难，既极大便利了港澳居民在内地的学习、工作、生活，又有效降低了人员跨境流动的染疫风险，受到广大港澳同胞的普遍肯定。
据统计，截至2021年底，各地共为8.5万人次港澳居民换发、补发证件，大大减少了港澳居民往返港澳与内地的时间成本和经济负担，仅交通费一项就可以为申请人节省近2亿元。
[ 中国日报记者：]

新的一年，国家移民管理局在打击跨境犯罪、"放管服"改革以及疫情外防输入方面会有哪些新动作？
[ 国家移民管理局新闻发言人 政策法规司司长 陈杰：]

感谢您的提问。2022年的1月19日，国家移民管理局召开全国移民管理工作会议，对2022年工作作出了全面部署。新的一年，国家移民管理机构将坚持以习近平新时代中国特色社会主义思想为指导，坚持党的绝对领导、全面领导，进一步增强"四个意识"、坚定"四个自信"、做到"两个维护"，牢固树立以人民为中心的发展思想，坚持稳中求进工作总基调，以防范化解重大风险为基点，以做好党的二十大安保维稳工作为主线，统筹做好各方面工作，推进移民管理事业高质量发展。
在打击跨境违法犯罪方面，我们将持续深化专项严打整治，保持工作机制不变、打击力度不减、增强办案力量，突出"打团伙、摧网络、断通道"，持续开展集中打击妨害国（边）境管理犯罪专项斗争，持续深化"三非"外国人治理，持续推进"平安边境"建设，坚决捍卫国家政治安全，全力维护正常出入境管理秩序。在深化移民管理改革方面，充分运用体制、法治、科技、社会力量，大力推进政策、制度、管理、服务创新，全力服务促进构建新发展格局，为中外人员提供更加优质高效专业的移民管理服务。在做好疫情外防输入工作方面，我们将进一步细化完善防疫抗疫措施，毫不放松抓好常态化疫情防控，认真贯彻党中央关于统筹疫情防控和经济社会发展部署要求，在筑牢外防输入防线的同时，全力服务保障产业链供应链安全稳定畅通，服务保障正常人文交流和人员往来。
因为时间关系，我们的提问就到这里。非常感谢大家出席今天的新闻发布会。再过几天，春节就要到了，在这里，提前给各位媒体记者朋友、给广大出入境旅客和关心支持移民管理工作的海内外各界友人拜年，祝大家新春快乐，工作顺利，身体健康，万事如意！今天的发布会到此结束。各位记者朋友如果有进一步的采访需求，请和国家移民管理局新闻发言人办公室联系。我们下次再见。谢谢。
