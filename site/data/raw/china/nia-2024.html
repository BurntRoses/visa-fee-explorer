　　首先，我向大家通报2024年移民管理主要数据和工作情况。

　　2024年，全国移民管理机构坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届二中、三中全会精神，坚定不移贯彻总体国家安全观，持续深化移民管理服务政策制度改革创新，充分发挥职能作用，全力以赴防风险、保安全、护稳定、促发展，有力维护国家政治安全、国门边境稳定和出入境管理秩序，有力服务促进高水平开放高质量发展，顺利完成了全年各项工作任务。

　　2024年，全国移民管理机构累计查验出入境人员6.1亿人次，同比上升43.9%；其中内地居民2.91亿人次、港澳台居民2.54亿人次、外国人6488.2万人次，同比分别上升41.3%、38.8%、82.9%。全年累计查验出入境交通运输工具3256.6万架（列、艘、辆）次，同比上升38.8%；其中飞机87.9万架次、列车10.1万列次、船舶43.7万艘次、机动车辆3114.9万辆次，同比分别上升62.6%、11%、8.2 %、38.9 %。共签发普通护照2331.9万本、内地（大陆）居民往来港澳台证件签注9451.4万张（件）次，同比分别上升26.5%、9.8%，签发港澳台居民来往内地（大陆）通行证257.8万张，相较2023年疫情后集中办证高峰稍有下降；签发外国人签证证件259.7万本次、同比上升52.3%，免签入境外国人2011.5万人次、同比上升112.3%。移民局政务服务平台为中外出入境人员提供查询等政务服务1.3亿人次，为港澳台居民、海外华侨和外国人免费提供身份核验服务3407万人次；国家移民管理机构12367服务热线受理中外人员咨询、意见建议等来电708.41万通，平均满意率达99.36%。

　　2024年，全国移民管理机构深化移民管理服务改革，加强政策制度精准供给，为高水平开放高质量发展注入新活力新动能，先后推出240小时过境免签、外国旅游团乘坐邮轮入境免签、扩大59国人员入境海南事由等18项便利外国人来华政策举措，持续优化过境免签、区域性入境免签、口岸签证政策，在北京首都等9个枢纽机场实施24小时直接过境免办查验手续，主动配合相关主管部门推进外籍人员支付、住宿、交通等便利化，有力服务稳外资稳外贸。围绕服务区域协调发展战略、区域重大战略，在上海试点实施电子口岸签证等一批移民出入境管理改革措施，实施推动东北全面振兴、中部地区崛起、海南自贸港建设、云南建设面向南亚东南亚辐射中心等若干措施，出台支持中越德天（板约）瀑布跨境旅游合作区等开放平台若干措施，支持一大批口岸对外开放，助力重点区域加快塑造开放发展新格局。围绕支持港澳更好融入国家发展大局、促进两岸融合发展，推出便利非中国籍港澳永久性居民来往内地政策，实施支持福建建设两岸融合发展示范区十项出入境政策措施，扩大往来港澳人才签注签发范围，创新实行赴港澳商务签注“就近办”“智能办”，新增10个赴港澳“个人游”签注签发城市，拓展实施赴港澳旅游“一周一行”“一签多行”，签发“琴澳游”旅游签注等便民利企政策措施，有力服务对港澳台工作大局。以“高效办成一件事”为牵引，在北京等20个城市试点实施内地居民换发补发普通护照、往来港澳通行证、往来台湾通行证“全程网办”，实现办理出入境证件“一次都不跑”，试点启用“免出示证件”通道，新增浙江文成等22个县级公安机关就近就便受理签发外国人签证证件，持续深化政务服务便捷化、边检通关便利化，不断提升移民管理服务效能。

　　2024年，全国移民管理机构始终把维护国家政治安全置于首位，坚定不移贯彻总体国家安全观，坚持严格规范公正文明执法，统筹推进严厉打击妨害国（边）境管理犯罪“獴猎”行动-2024，深入开展夏季治安打击整治行动，持续深化“三非”外国人治理，坚决筑牢国门边境安全稳定屏障，坚决维护国家主权、安全和发展利益。牵头联合各部委首次评定5个平安边境模范县市、20个模范乡镇，以点带面辐射带动边境地区治理能力水平。全年共侦办妨害国（边）境管理犯罪案件3.5万余起，抓获犯罪嫌疑人7.9万余人，打掉犯罪团伙906个。其中，挂牌督办重特大案件328起，抓获“捕蛇”目标逃犯518名。严厉打击边境地区涉枪爆、贩毒走私等违法犯罪，查获毒品案件494起653人，其中万克以上案件105起，缴获各类毒品7.8吨；查缴各类枪支2000余支，子弹10万余发。我们成功举办上海合作组织成员国主管机关边防部门领导人第十次会议、全球公共安全合作论坛移民管理合作分论坛，深度参与全球移民治理，以合作保安全、以安全促发展。

　　一年来移民管理工作取得的成绩，根本在于以习近平同志为核心的党中央坚强领导，在于习近平新时代中国特色社会主义思想的科学指引，得益于社会各界和广大出入境人员的理解支持，也凝聚着移民管理机构广大民警职工的团结奋斗、奉献牺牲。

　　2024年，全国移民管理机构1个集体获评全国民族团结进步模范集体、3名民辅警获评全国民族团结进步模范个人，受到了党中央国务院隆重表彰。80余个集体、240余名个人荣获省部级以上表彰或二等功以上奖励。15名民辅警牺牲殉职，66名民辅警因公负伤，用鲜血和生命践行了“人民公安为人民”的庄严承诺。

　　新的一年，我们将忠实履行好党和人民赋予的新时代移民管理使命任务，接续奋斗、砥砺前行，奋力推进移民管理工作现代化，为推进强国建设、民族复兴伟业贡献更大移民管理力量！

[ 东方卫视记者 ]：

　　我们注意到2024年国家移民局推出一系列便利外国人来华政策举措，其中最引人注意的就是全面放宽优化过境免签政策。能否简要介绍一下这些举措及实施效果。
[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

　　过去一年，国家移民局聚焦推进更高水平对外开放，持续推出一系列灵活、便利的外国人来华政策，会同有关部门对38个国家实行单方面免签、与26个国家实现全面互免签证，同时持续深化移民管理改革和政策制度创新，不断优化口岸签证、过境免签、区域性入境免签等政策，积极促进人员交流交往，外籍人员来华数量明显增长。

　　一是推出便利外籍人员来华5项措施，放宽来华外籍人员申办口岸签证条件，为在华外籍人员就近办理签证延期换发补发、申办再入境签证等提供便利。

　　二是在海南自由贸易港实施更加宽松的免签入境政策，扩大59国人员免签入境海南事由，实施港澳地区外国旅游团入境海南144小时免签政策。

　　三是全面实施外国旅游团乘坐邮轮入境免签政策，并同步将大连、连云港、温州、舟山、广州、深圳、北海等地的7 个邮轮口岸新增为我国过境免签政策适用口岸。

　　四是全面放宽优化过境免签政策，将过境免签外国人在中国境内停留时间由原72小时和144小时均延长为240小时，政策适用口岸总数从原有的39个增加至60个，适用省份总数从19个增加至24个。

　　据统计，2024年，国家移民局累计签发口岸签证147.6万证次，同比增长87.3%，为7.2万人次提供就近办理签证延期换发补发便利。大家最为关注的过境免签政策，适用人数同比上升113.5%，特别是全面放宽优化政策后，适用该政策来华人数环比上升29.5%。

　　各项利好政策不断推出，让外国游客“说来就来”游中国成为现实，带火了我国入境游市场。“China Travel”（中国游）主题媒体流量在国际互联网突破10亿，“周五下班去中国”成为国际新热潮，更多的外国朋友来到中国，亲身感受到新时代中国之美。相关报告显示，我国入境游人数和消费快速增长的同时，外国游客满意度也在稳步提高。便捷的来华渠道不仅促进了中外人员往来和文化交流，也为丰富入境旅游形态，加速区域旅游一体化合作进程，推动全域旅游协同发展注入了新动能。

　　下一步，国家移民局将聚焦服务促进高水平开放高质量发展，稳步扩大制度型开放，不断释放免签政策红利，进一步便利中外人员往来和交流交往。

[ 中国交通广播记者 ]：

　　中国出入境管理局去年12月1日起在广东深圳市实施了赴香港旅游“一签多行”政策，今年1月1日起又在广东珠海市实施了赴澳门“一周一行”政策、在横琴粤澳深度合作区实施了赴澳门“一签多行”政策，请介绍一下政策实施以来的情况？在确保政策实施方面采取了哪些措施？
[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

　  感谢您的提问。广东省深圳市、珠海市和横琴粤澳深度合作区赴港澳旅游“一签多行”“一周一行”政策实施以来，港澳特区政府和社会各界、广大媒体给予高度关注和积极评价。据统计，2024年12月1日以来，公安机关出入境管理部门共签发赴香港旅游“一签多行”签注29.9万件次；今年1月1日以来，签发赴澳门旅游“一周一行”签注5.9万件次，签发赴澳门旅游“一签多行”签注6000余件次，赴港澳客流增幅明显，内地与港澳居民双向奔赴持续升温，证件签发安全有序，口岸通关高效顺畅。政策的实施，对进一步便利内地居民前往港澳观光旅游、购物消费，推动港澳经济社会发展，服务港澳更好融入国家发展大局具有重要积极意义。

　  为确保政策顺利实施，我局重点做好三个方面工作，一是优化升级出入境证件签发及边检查验系统。加强对相关地方公安机关出入境管理部门和边检机关的指导和培训，及时对接港澳特区出入境管理部门做好政策协同，全力保障广大申请人有序办证、顺畅通关。二是积极应对出入境办证高峰。政策实施后，群众办证热情高涨。2024年12月1日和2025年1月1日当天分别有近万人办证。为有效应对办证高峰，我局指导广东省公安机关出入境管理部门加强勤务配备和窗口引导，确保前台咨询接待、人工窗口受理和智能设备服务等环节警力充足，同时做好宣传引导工作，积极开展政策宣介和咨询解答，及时回应群众关心关切，实现港澳游“即刻出发、说走就走”。三是主动提供优质通关服务。部署深圳、珠海边检总站针对政策实施初期客流增长，叠加岁末年初粤港口岸传统客流高峰等情形，在圣诞节、元旦假期前后启动应急处置预案，增配现场执勤警力，加大前置引导力度，为政策落地实施提供有力保障。政策实施后，在促进人员往来方面成效明显。据统计，2024年12月1日以来，深圳市居民出境赴香港104万人次，同比增长22.3%；今年1月1日以来，珠海市居民出境赴澳门25.7万人次，同比增长26.1%。

  下步，我局将深入学习贯彻习近平主席在庆祝澳门回归祖国25周年大会重要讲话精神，按照中央关于港澳工作决策部署，持续加强往来港澳出入境管理服务工作，确保赴港澳旅游“一签多行”“一周一行”政策有序实施，进一步促进人员交流交往和港澳经济社会发展，维护港澳地区长期繁荣稳定。

[ 总台央视记者 ]：

 　 刚才通报中提到，2024年国家移民管理局打击妨害国（边）境管理犯罪战果丰硕。新的一年还将有哪些新的部署和行动？

[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

    谢谢您的提问。2024年，国家移民管理局以深入打击妨害国（边）境管理犯罪“獴猎”行动-2024为依托，指挥部署全国移民管理机构，会同各警种各部门，成功打掉了一大批组织偷渡犯罪团伙，斩断了一大批偷渡通道，摧毁了一大批非法利益链条，极大震慑了境内外犯罪分子的嚣张气焰，同时也积累了很多宝贵经验。2025年，国家移民管理局将以更高标准、更细部署、更实举措，继续开展专项打击行动，着力构建“专业+机制+大数据”新型警务运行模式，健全完善移民管理系统侦查打击体系，不断提升打击妨害国（边）境管理犯罪新质战斗力，全力维护国家安全、国门边境稳定和出入境管理秩序。一是持续保持重拳严惩攻势。我们将继续按照“打团伙、断通道、斩‘蛇头’、摧网络”的工作目标，坚持同类型案件集中研判，跨区域案件协同侦办，全链条犯罪起底打击，分波次部署开展集群战役，持续保持对各类妨害国（边）境管理犯罪的严打高压态势，不间断掀起打击热潮。二是持续强化“打链断血”力度。坚持深挖严打幕后，依法严惩犯罪团伙，坚决铲除骨干头目，实现“挖出一个、打掉一串”的效果。依法查扣涉案的车辆、船舶等，依法追缴违法所得，摧毁犯罪团伙根基，防止其“生血再造”，彻底铲除犯罪网络。三是持续加强追逃缉捕措施。深入开展追捕妨害国（边）境管理犯罪在逃重要犯罪嫌疑人攻坚行动，通过多种方式手段，全面挤压境内外在逃人员的藏匿空间，全力把潜藏、蛰伏、外逃的幕后组织者、运送者、骨干分子缉捕归案。四是持续增强“打治一体”合力。推动将反偷渡工作纳入基层综合治理范畴，对重点地区开展集中整治活动，排查严管涉偷渡违法犯罪重点人员，依法取缔一批违规中介机构，积极会同各部门形成问题联治、风险联控、平安联创的口岸边境治理新局面。五是持续深化国际执法合作。利用各类执法合作平台和渠道，推动建立和完善执法合作机制，共同维护国家间正常出入境管理秩序。

[ 北京广播电视台记者 ]：

　  春节假期即将到来，全国口岸出入境游客数量不断攀升，国家移民管理局在服务保障中外游客顺畅通关方面将采取哪些措施？
[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

　　谢谢您的提问。随着过境免签、免签入境等便利人员往来政策的持续优化，中外人员交流日益频繁、快速增长，为保障中外游客顺畅通关，我们主要采取以下三方面措施：一是加强出入境流量和口岸运行情况监测。在节假日期间及时发布口岸通关“两公布一提示”，为出入境人员行程安排提供参考。二是科学组织勤务。预置充足警力，开足查验通道，创新查验模式，加强提示引导，确保客流高峰时段及时削峰、动态削峰，确保中国公民出入境通关排队不超过30分钟。三是密切与有关部门协作配合。稳妥做好通关高峰期客流疏导和交通配套综合保障，进一步提升口岸通关保障能力，共同确保口岸通关安全高效顺畅。同时，我们将坚持依法履职，牢固树立严格规范公正文明的执法理念，在切实保障公民出国出境合法权益的同时，坚决依法防范打击涉出入境领域的违法犯罪，构建合法、安全、有序的出入境管理秩序。主动加强安全风险提示提醒，引导公民危地不往、险地不去，避免遭受人身侵害和财产损失。

　　在此，提醒广大出入境旅客，在通关过程中如遇困难，可随时拨打国家移民管理局12367服务热线或向现场执勤的移民管理警察寻求帮助。

[ 人民日报记者 ]：

　  当前，港澳台居民、海外华侨来往更加频繁，联系愈发紧密，持用出入境证件观光旅游、生活发展的需求更加凸显。近年来，国家移民管理局会同相关行业主管部门持续推进出入境证件便利化应用工作，取得了显著成效，能否介绍一下有关情况？谢谢。

[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

　　感谢您的提问。为进一步便利港澳台居民、海外华侨在境内生活发展，我局于2019年专门研发建成出入境证件身份认证平台，会同教育部、公安部、中国人民银行、国铁集团等17个部门，强力推进出入境证件便利化应用工作。截至目前，服务领域和范围已经覆盖交通、金融、电信、教育、医疗、社保、工商、税务、住宿、文旅等10大领域40余类事项，港澳台居民、海外华侨可以享受便捷高效、智能精准的办证办事便利。

　　2024年，我局会同相关部门大力加速深化出入境证件便利化应用工作，取得三方面新成效：一是应用领域实现新拓展。会同文化和旅游部、国家文物局积极推进出入境证件在文旅领域的便利化应用，持证人在逛景区、看演出、进场馆、住民宿等方面将更加方便快捷，可以更好感受祖国的发展进步和璀璨文化、美丽风光。同时，与相关互联网企业建立联络推广机制，为持证人办理互联网应用事项提供更加高效便捷服务，让广大同胞更好享有国家互联网产业快速发展带来的“红利”。二是用证人数实现新增长。2024年，我局出入境证件身份认证平台共为港澳台居民、海外华侨提供实时免费核验服务3256万人次，同比增长5.4%，其中回乡证核验数达2109万人次，累计突破1亿人次，台胞证核验数达678万人次，同比增长25.1%，并保持高速增长态势，越来越多的港澳台居民、海外华侨可以顺利办证办事、工作生活、经商办企，有力促进人员往来，深化交流交融。三是示范区建设取得新成效。广东、福建是港澳台居民的聚集地，我局部署两省公安机关出入境管理部门充分发挥区位优势，率先建设便利化应用示范区，赋予其更多先行先试任务，探索新的应用领域、应用事项，全面梳理近300项港澳台居民高频使用的政务、公共服务，不断优化持证人用证体验，以示范带动作用为全面深化便利化应用工作积累经验做法，为广大同胞深度参与国家建设提供良好环境。

　　出入境证件便利化应用是涉及各领域、多部门的全国性、基础性工程，是一项持续推进的长期工作。下步，我局将紧盯港澳台居民、海外华侨的用证新需求新期待，不断拓展出入境证件的应用领域和服务范围。针对在内地（大陆）的港澳台居民希望实现通行证和居住证信息关联、通行证遗失后方便紧急出行等现实迫切诉求，积极研究推出“双证关联”服务、出具临时身份证明，努力为广大同胞提供更好服务、更多便利，切实为其办实事解难题。

[ 三沙卫视记者 ]：

　  刚才通报中提到，2024年全国移民管理机构深入开展夏季治安打击整治行动，有力震慑了跨境违法犯罪活动，各类突出风险隐患得到有效化解，成效非常明显。那么近期有无新的部署和行动呢？
[ 国家移民管理局新闻发言人 综合司副司长 吕宁 ]：

　　感谢您的提问。根据公安部统一部署，自2024年11月底至2025年2月底，国家移民管理局部署全国移民管理机构开展冬季治安打击整治行动（以下称“冬季行动”），主要任务是严厉打击具有冬季特点的跨境违法犯罪活动，及时化解口岸边境风险隐患，切实维护口岸边境安全稳定。“冬季行动”开展以来，共侦办妨害国（边）境管理犯罪案件2811起，抓获中外籍犯罪嫌疑人员9985人，打掉犯罪团伙62个，查扣涉案交通工具208辆（艘），斩断多条偷渡通道；破获毒品案件55起，抓获犯罪嫌疑人77人，查获毒品254.9公斤；查获非法持有枪支案件11起，抓获犯罪嫌疑人4人，收缴各类枪支60支、子弹2055发；破获走私案件1680起，抓获涉案人员539人，查获各类走私物品案值7760余万元。全国移民管理机构“冬季行动”取得了阶段性丰硕战果。

　　进入新的一年，国家移民管理局将持续深入推进“冬季行动”， 重点强化冬季违法犯罪活动打击和治安突出问题整治；重点强化口岸边境风险隐患梳理摸排和防范处置；重点夯实移民管理基层基础和服务群众工作，不断提升口岸边境社会治安驾驭能力，不断提升移民管理新质战斗力，不断提升边境辖区人民群众和出入境人员安全感、满意度，确保“冬季行动”取得新的更大成效。
